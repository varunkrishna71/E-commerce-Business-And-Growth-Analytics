# Sales Data Analysis and Business Insights

## Overview
An exploratory data analysis project focused on understanding
retail sales performance, profitability, product categories,
and customer segments using Python.

## Objectives
- Analyze monthly sales trends.
- Identify high- and low-performing product categories.
- Evaluate sub-category sales and profitability.
- Analyze monthly profit trends.
- Compare sales and profit across customer segments.
- Calculate sales-to-profit ratio and profit margin.

## Technologies & Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Aggregation
- Date-Time Analysis
- Data Visualization
- Business Insights

## Project Files
- `Sales_Analysis.ipynb`: Analysis and visualizations.
- `Sample - Superstore.csv`: Dataset, if redistribution is permitted.
- `requirements.txt`: Required libraries.

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Open `Sales_Analysis.ipynb` in Jupyter Notebook.
4. Ensure the CSV file is in the correct directory.
5. Run the notebook cells in order.

## Conclusion
The project uses exploratory analysis and visualizations to
understand sales and profitability patterns and support
data-driven business decisions.
